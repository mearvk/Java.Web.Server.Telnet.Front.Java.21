TIPS & TRICKS
═══════════════════════════════════════════════════════════════════════════════════

Run everything in background with logging:
  $ bash scripts/start-all.sh | tee start-all.log &

Monitor startup progress:
  $ tail -f start-all.log

Set default Tomcat home for session:
  $ export CATALINA_HOME=/opt/tomcat

Log all commands for debugging:
  $ set -x
  $ bash scripts/start-all.sh

Redirect output to file:
  $ bash scripts/start-all.sh > startup.log 2>&1

Parallel startup (risky, advanced):
  $ bash scripts/start-backends.sh &
  $ bash scripts/start-frontends.sh &
  $ wait

Safe shutdown before restart:
  $ bash scripts/shutdown-all.sh && sleep 5 && bash scripts/start-all.sh

Test only one backend:
  $ cd modules/AE6E66 && bash start-backend.sh && bash shutdown-backend.sh

Full diagnostic:
  $ bash scripts/status.sh > pre-check.log
  $ bash scripts/start-all.sh | tee startup.log
  $ bash scripts/status.sh > post-check.log
  $ diff pre-check.log post-check.log
