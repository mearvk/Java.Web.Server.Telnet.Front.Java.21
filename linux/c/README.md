This directory contains portable C source files intended to build on Linux, macOS,
and Windows with a Unix-like shell toolchain (for example: GCC + MSYS2/MinGW or a standard GNU make environment).

Build steps:

  make
  make clean

If you are using Windows without a Unix-like shell, install MSYS2 or Git Bash so the
`find`, `gcc`, and `ar` toolchain is available to GNU make.
