  - BaseServer(String,Integer)  Binds ServerSocket on host:port.
  - BaseServer(Integer)         Binds ServerSocket on localhost:port.

                                NweConfig "HEURISTIC_CLASSIFIER"), then creates
                                Connection, spawns ConnectionPoller, records to

                  this.PORT on every accept.

HEURISTIC CLASSIFIER  (source/heuristics/)
================================================================================

heuristics.HeuristicClassifier
  PUBLIC_PORTS = {49152, 5512, 6682, 49155, 49188}
  Gated by NweConfig.isEnabled("HEURISTIC_CLASSIFIER") in BaseServer.run().
  Per-instance state (one classifier per BaseServer):
    ipTimestamps   IP → rolling list of epoch-second timestamps (60s window)
    ipPorts        IP → set of distinct ports probed
    countryCount   countryCode → connection count
  Built-in rules (score 0–100, threat ≥ 40 → socket closed immediately):
    checkIpRate()           IP repetition: ≥20 conn/60s → +40; ≥10 → +15
    checkPortScan()         ≥3 distinct ports from same IP → +30
    checkGeoConcentration() single country ≥30% of total (min 5 sample) → +20
    checkPayload()          bad keywords +15 each; large-alloc patterns +20;
                            spin-loop patterns +25; system binary paths +30;
                            constructor-loop pattern +20
  Extensibility:
    implements IHeuristicModule   — register independent scoring module
    extends AbstractHeuristic     — inherits port helpers + warn()/pass() API
    register(IHeuristicModule)    — add at runtime

heuristics.ModuleHeuristics
  evaluate(Path) → Result (score 0–100, suitable if ≥70)
  Checks: file type (+20), non-empty (+10), size ≤50MB (+10), name safe (+5)
  Type-specific:
    checkJar()         MANIFEST.MF (+15), .class files (+25)
    checkZip()         entry count (+30)
    checkJavaSource()  public type (+20), package (+10), no exec (+10),
                       then checkSourceSecurity():
                         large array allocation  (−20)
                         spin loop               (−25 / −10 if exit present)
                         system binary exec path (−30)
                         constructor loop no exit(−20)

BINARY HTTP SERVER  (source/http/)
================================================================================

http.BinaryHttpServer  (extends Thread, daemon)  PORT = 49144
  Apache dir: /var/www/html/nwe  (override via <apache-root> in nwe-config.xml)
  Public URL: http://localhost/nwe  (override via <apache-url> in nwe-config.xml)

  Protocol (raw TCP, newline-framed header then binary payload):

    PUT <filename>\n
    <4-byte big-endian length><binary bytes>
      → writes file to apache-root/<8-char-uuid>-<filename>
      → returns: OK http://localhost/nwe/<uuid>-<filename>

    GET <url>\n
      → downloads http/https URL (10s connect / 30s read timeout)
      → saves to apache-root/<8-char-uuid>-<basename>
      → returns: OK http://localhost/nwe/<uuid>-<basename>

  Security:
    - Only http/https GET URLs accepted (no file://, no arbitrary schemes)
    - Filenames stripped to [a-zA-Z0-9._-] via safeName()
    - Path.getFileName() used to prevent directory traversal on both PUT and GET

ANTIVIRUS  (source/antivirus/)
================================================================================

antivirus.AntivirusScanner  (no port; scheduled daemon)
  Gated by NweConfig.isEnabled("ANTIVIRUS").
  schedule  read from nwe-config.xml <schedule>: hourly|daily|weekly|monthly|yearly
  scan-path read from nwe-config.xml <scan-path> (default ".")
  - start()        Launches ScheduledExecutorService daemon at configured period.
  - scan()         Calls runClamScan() then runIntegrityCheck().
  - runClamScan()  clamscan -r --suppress-ok-results <path>; logs CLEAN or ALERT.
                   Degrades gracefully if clamscan not on PATH.
  - runIntegrityCheck()
                   SHA-256 baseline over *.java *.class *.jar *.sh *.xml *.properties.
                   First run: captures baseline.
                   Subsequent runs: reports CHANGED and NEW files.

SUMMARY
================================================================================

NWE opens 10 public TCP ports at startup (all gated by nwe-config.xml):

  PORT   SERVICE                   PURPOSE
  ─────  ────────────────────────  ─────────────────────────────────────────────
  49133  WeatherServer             Current weather by city or lat,lon via wttr.in
  49144  BinaryHttpServer          Binary → HTTP link; PUT binary or GET URL → Apache2 dir
  49152  NitroWebExpress           Main entry; telnet proxy; AES/BTC bridge hub
   5512  AESCompliant              AES 2.0 DSS 5.0 encryption sub-server
   6682  BitcoinCompliant          Bitcoin lightweight trading sub-server
   7743  RSACompliant              RSA encryption sub-server
   7744  DSACompliant              DSA encryption sub-server
  49155  ConnectionStatusServer    Health report: geo, threads, live IPs, memory
                                   Language selection (20-min window); 20-min session
  49166  ModuleInstallationService Install/unload/restart NWE modules; admin auth
  49177  ASCIICreatorServer        Issue/view binary ASCII signatures (National ID)
  49188  ModuleLoaderDaemon        OS-level push/pull/replicate module daemon
  49199  Communicator              1-hour persistent chat; scheduled geo-delivery

All ports share:
  • HeuristicClassifier gate (rate, port-scan, geo, payload — drops threats ≥40)
  • LanguagePack (ja cn ru th es fr de it en) via "lang <code>" command
  • N21Store MySQL persistence (XML fallback when DB unavailable)

Background daemons (no port):
  • AntivirusScanner   ClamAV scan + SHA-256 integrity check (hourly–yearly)
  • Communicator.MessagePoller  Scheduled message delivery (60s poll)
  • TelnetProxyLivenessMonitor  Telnet process health + auto-reconnect (15s)
