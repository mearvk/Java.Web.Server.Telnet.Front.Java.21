ENTRY POINT
================================================================================

Main (source/Main.java)
  - main(String...args)         Entry point; instantiates Main.

SERVER LAYER  (source/server/)
================================================================================

server.base.BaseServer  (abstract, extends Thread)
  - BaseServer()                Default constructor.
  - BaseServer(String,Integer)  Binds ServerSocket on host:port.
  - BaseServer(Integer)         Binds ServerSocket on localhost:port.
  - run()                       Accept loop: creates Connection, sets up
                                reader/writer, spawns ConnectionPoller thread,
                                adds connection to CURRENT_CONNECTIONS.

server.nitro.WebExpress  (extends BaseServer)
  - WebExpress()                No-arg constructor.
  - WebExpress(host,port,name,  Wires TelnetInstaller, TelnetCommunicationProxy,
    telnetEnabled)              MessageQueueSorter; starts sorter thread.

server.nitro.NitroWebExpress  (extends WebExpress)
  - NitroWebExpress(port,host,  Full constructor; calls WebExpress super,
    threadName)                 initialises NationalID, sets static SELF ref.

  NitroWebExpress.Aspect        Bridge holder for AES and Bitcoin components.
    - Aspect(WebExpress)
    - AES_COMPONENT             AESCompliant instance (wired from Main).
    - BITCOIN_COMPONENT         BitcoinCompliant instance (wired from Main).

  NitroWebExpress.Aspect.AESCompliant  (extends WebExpress)
    - AESCompliant(host,port,   Starts AES WebExpress sub-server.
      threadName,telnetEnabled)
    - MessageOutputHandler
        send_message(StringBuffer)
        send_message(String)    Routes outbound AES messages.

  NitroWebExpress.Aspect.BitcoinCompliant  (extends WebExpress)
    - BitcoinCompliant(host,    Starts Bitcoin WebExpress sub-server.
      port,threadName,enabled)
    - MessageOutputHandler
        send_message(StringBuffer)
        send_message(String)    Routes outbound Bitcoin messages.
    - MessageQueueSorter (inner Thread)
        run()                   Drains MESSAGE_QUEUE; writes to Telnet proxy
                                writer; cleans disconnected clients from
                                CURRENT_CONNECTIONS.
        addMessage(Message)
        getMessageQueue()
        getMessageQueueSize()

server.nitro.ConnectionStatusServer  (extends Thread)
  - ConnectionStatusServer(host, watched, watchedPort)
  - run()                       Binds port 49155; accepts status queries.
  - respond(Socket)             Returns plain-text report: remote IP, geo,
                                uptime, memory, connection count. Persists
                                geo + snapshot to N21Store.
  - fetchGeo(String ip)         HTTP lookup via ip-api.com; returns "City, Country".

telnet.TelnetInstaller
  - TelnetInstaller(WebExpress)  Starts OS telnet process to REMOTE_SITE:REMOTE_PORT;
                                 wires process_builder, process, reader, writer.

telnet.TelnetCommunicationProxy

                                TelnetProxyCommunicator, TelnetOutputBuilder,

    - run()                     Reads lines from telnet process; enqueues to
                                input_builder.telnet_message_queue; also builds

  - TelnetOutputBuilder(TelnetCommunicationProxy)

                                to proxy.writer (telnet process stdin).

  - TelnetInputBuilder(TelnetCommunicationProxy)

                                to proxy.writer.
  - setBuffer(StringBuffer)

  - TelnetMessageQueue(Integer size)
  - TelnetMessageQueue(BaseServer)
  - add(Message)
  - remove(Message)
  - sleep(Message)              Alias of add; enqueues and notifies.
  - size()
  - delete(Message)             Nulls the messages list (destructive).
  Message (inner static class)
    Fields: PORT, protocol, SOCKET, TIMESTAMP, MESSAGE_BUFFER, internet_address

telnet.TelnetProxyLivenessMonitor  (extends Thread, daemon)
  - TelnetProxyLivenessMonitor(TelnetCommunicationProxy)
  - run()                       Probes proxy every 15s when clients connected;
                                idles every 5s when no clients; calls reconnect()
                                on failure.
  - isProxyAlive()              Checks process.isAlive() and flushes writer.
  - reconnect()                 Destroys dead process; runs TelnetInstaller;
                                rewires proxy streams.

MODULE LOADER  (source/loader/)
================================================================================

loader.ModuleLoaderDaemon  (extends Thread, daemon)
  PORT = 49188

  Standalone OS-installable module loader.  Runs independently of NWE on any
  server that carries the install mat.  Port privilege is granted externally
  by the national port-authority database before clients may push or replicate.

  Commands (TCP text protocol):
    identify <nationalId>               Identify via N21Store lookup
    token    <port-registry-token>      Present national port-authority token
    push     <name> <sha256> <bytes>    Install a module (binary follows inline)
    pull     <name>                     Download an installed module
    list                                List all installed modules + SHA-256 + size
    remove   <name>                     Remove a module (token required)
    replicate <host:port> <name>        Duplicate module to remote ModuleLoaderDaemon
    quit                                Close connection

  Static:
    registerPortToken(token, nationalId)  Register a port-registry token
                                          (called by national port-authority DB)

  DaemonModule (inner static)             NAME, PATH, SHA256, SIZE, INSTALLED_AT

  Wired into NitroWebExpress.Aspect as MODULE_LOADER_DAEMON field;
  started via Aspect.start() alongside all other NWE services.
